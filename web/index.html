支持 1–16 个本机 HTTP / SOCKS5 出口。列表越靠前优先级越高，第一个是首选出口。名称仅用于识别，不限定代理软件。修改后需要保存。

默认 17890，HTTP / SOCKS5 共用。修改后同步已启用的接入；现有连接可能中断，终端及容器需重新打开或创建。手动配置的代理地址需自行修改。管理端口 17880 / 17881 / 17882 不可占用。

默认关闭。开启后按最近 3 轮平滑延迟择优，暂停优先级恢复回切；应用固定规则始终优先。当前出口故障时跳过防抖等待，只切换新连接。

检测地址与直连规则

本机、局域网和 Tailscale 私有地址直连。其他进入网关的请求按出口优先级转发；出口客户端仍可按自身规则分流。上游暂不支持账号密码认证。

应用固定代理

选择应用和代理客户端，保存后网关自动识别并配置接入。无需去应用里填代理地址或手动找程序路径。固定客户端故障时不改道。

桌面版和 CLI 分别显示。首次接入后，已打开的应用或终端可能需要重启一次。其他接入应用继续跟随默认策略。手动地址和路径配置保留在高级规则中。

针对已保存的配置，仅自动模式可用。

应用接入与固定规则状态

活动连接仅反映当前命中情况，暂无活动连接不代表规则未生效。每项接入独立启用，并保存原值供恢复。

接入项按系统显示。Git SSH 不受 HTTP 代理选项控制。终端、Docker 和 WSL 的适用范围及手动配置见 README。
